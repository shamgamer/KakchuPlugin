## Features (configurable):
* Discord Webhook Alerts For Errors and Warns
* Automatic Restarts (deprecated will be removed in plugin version 27.1)
* Custom /help command
* Custom /map command
* Server Uptime Tracking
* AxRewards Login Notifications
* AxRewards Streaks and graces

## Plugin Information:

Check [versions.json](https://github.com/shamgamer/ShamPlugin/blob/master/versions.json) for plugin version compatability (if a version isn't listed it has not been tested)

The plugin has used AI to assist in its development.

All Ai contributions are manually checked and tested by me to ensure their quality and function.

No AI art will ever be used for this project.
